# Vocab Story → IPA Viewer (one paragraph per run)

Given a plain English story at `vocab/stories/{yymmdd}_{slug}.md`, maintain two artifacts:

1. **`vocab/json/{slug}_ipa.json`** — the canonical structured data (English + IPA per paragraph, plus a phonetic `nuclei` analysis per paragraph). You author this, **one section at a time**.
2. **`vocab/html/{slug}_ipa.html`** — a self-contained reader rendered from the JSON by `build_html.py` (deterministic; do not hand-write it).

**This skill generates IPA for the NEXT paragraph only — never the whole article.** Each run: find the next not-yet-done paragraph, transcribe just that one, append it to the JSON, refresh the HTML, and report how many remain. Run the skill again to do the following paragraph. (A paragraph counts as *done* once its JSON section has a non-empty `nuclei` list.)

Generate **directly from the plain story**. Do **not** create or read an intermediate `*_ipa.md` file.

**`vocab/US_IPA.json` is the ground-truth pronunciation dictionary** — a flat `{lowercase-word: bare-IPA}` map (no slashes) holding the citation form of every word, e.g. `{"walk": "wɑːk", "to": "tuː"}`. Per-word IPA is **looked up here first**; only words missing from it are generated by you and **merged back in**, so the dictionary grows and stays the single source of truth. To change how a word is pronounced everywhere, edit the dictionary — never overwrite an existing entry from inside this skill.

## Input

The target story is: $ARGUMENTS

A path to a file under `vocab/stories/` (e.g. `vocab/stories/260613_the_grand_tour.md`). If the argument is empty, ask which story to process. The output stem is the source filename with `_ipa` appended (`260613_the_grand_tour` → `260613_the_grand_tour_ipa`).

## Execution Flow

### Phase 1 — Find the next paragraph

Ask the driver which paragraph is next and get its words resolved against the dictionary in one step:

```bash
python .claude/skills/vocab-ipa-generate/paragraph_tool.py next vocab/stories/{yymmdd}_{slug}.md
```

It prints:

```json
{ "title": "…", "subtitle": "…", "total": 9, "completed": 1,
  "next_index": 1, "next_text": "<paragraph verbatim>",
  "found": { "word": "ipa", … }, "missing": [ "word", … ] }
```

- **If `next_index` is `null`** → every paragraph is already done. Tell the user the viewer is complete and stop (optionally re-render the HTML).
- Otherwise you will transcribe **only** `next_text` (the paragraph at `next_index`). `found` is the authoritative dictionary IPA for that paragraph's words — **use it verbatim**. `missing` is the (usually short) list you must generate.

The driver does the segmentation: it drops the leading `# Title` and horizontal rules and splits on blank lines, so **paragraph = one section**, kept verbatim. Don't re-split or re-segment yourself.

### Phase 1.5 — Fill any missing words into the dictionary

For each word in `missing`, produce its **General American citation IPA** (bare, no slashes) following the phoneme set in Phase 2. These are dictionary citation forms — full strong forms with length marks (e.g. `to` → `tuː`, `walk` → `wɑːk`), not connected-speech reductions. Then merge them so the dictionary stays the source of truth:

```bash
echo '{"word1":"ipa1","word2":"ipa2"}' | python .claude/skills/vocab-ipa-generate/ipa_lookup.py merge -
```

`merge` never overwrites an existing entry. Re-run the Phase 1 `next` command and confirm `missing` is now `[]` before continuing. Now every word in this paragraph has an authoritative IPA (the `found` map plus your merged additions); Phases 2–3 **assemble** from these per-word forms rather than inventing them fresh.

> Allowed context override: `the` is `/ði/` before a vowel sound and `/ðə/` otherwise; `a` → `/ə/`. Apply these two standard allophonic variants when assembling; otherwise use the dictionary form as-is.

### Phase 2 — Transcribe this paragraph

Write **one** `ipa` string for the next paragraph — a **General American phonemic transcription** in `/ /` covering the whole paragraph, **assembled from the per-word dictionary forms** (join them in order; the only freehand judgement is the two allophonic overrides above and where stress/punctuation falls):

- `ˈ` before the primary-stressed syllable, `ˌ` for secondary stress, `ː` for long vowels.
- **Consistent General American (rhotic).** Use this phoneme set — do NOT use British symbols:
  - Vowels: `ɪ iː ɛ æ ə ʌ ɜːr ɑː ɔː ʊ uː eɪ aɪ ɔɪ aʊ oʊ`. R-colored: `ɑːr ɔːr ɜːr ɪr ɛr ʊr` and unstressed `ər`.
  - **LOT vowel = `/ɑː/`** (on, job, lot, hot, stop) — never British `/ɒ/`.
  - **Cloth set = `/ɔː/`** (lost, coffee, office, across, dog, long, Mekong) — words where historic `/ɒ/` is followed by `/f θ s ŋ ɡ/`. Keep cot–caught distinct (`/ɑː/` vs `/ɔː/`).
  - **"air" = `/ɛr/`** (their, stairs, bearings) — never `/ɛə(r)/`. Likewise `we're /wɪr/`, `you're /jʊr/`.
  - Pronounce every `r` (rhotic). Standard consonants incl. `θ ð ʃ ʒ tʃ dʒ ŋ j w`.
- Keep sentence boundaries inside the one `/ … /` block as `. ` (period + space) between sentences; keep commas, dashes, `?`/`!` where they fall. Mirror the existing `vocab/json/260613_the_grand_tour_ipa.json` style.

### Phase 3 — Analyze this paragraph

This section gets its own `nuclei` breakdown, computed from **this paragraph's own words only** (do not carry words over from other paragraphs). The `/IPA/` shown next to each word is its **dictionary form** — file each word under the vowel nucleus/nuclei that form contains.

**`nuclei`** — every **distinct vowel nucleus** that appears anywhere in this paragraph, each with the words that contain it (merge across all sentences of the paragraph; dedupe repeated words):
- `ipa` — the vowel in slashes (e.g. `/ɪ/`).
- `label` — **consistent format `"<keyword>" · <type>, <rounding>[, r-colored][, <stress>]`** so every card displays the same set of attributes. `keyword` is a plain-English hint (ih, ee, ah, aw, oo, uu, ay, eye, ow, oh, …). For **monophthongs**: `type` ∈ {**short**, **long**} + `rounding` ∈ {**rounded**, **unrounded**}. For **diphthongs**: just `diphthong` (they glide, so no fixed rounding). **`r-colored`** is an attribute (like rounding) — add it to any r-colored vowel (`ɜːr ɑːr ɔːr ər ɛr ɪr ʊr`); its unmarked default (a plain non-r vowel) writes nothing. Add a `stress` note **only** for the central pair that contrasts on stress: `/ə/` → `"uh" · short, unrounded, unstressed`, `/ʌ/` → `"uh" · short, unrounded, stressed`. Reference mapping:
  - short, unrounded: `ɪ ɛ æ`  · short, rounded: `ʊ`
  - long, unrounded: `iː ɑː`  · long, rounded: `uː ɔː`
  - r-colored (attribute): `ɜːr ɑːr` (long, r-colored) · `ɔːr` (long, rounded, r-colored) · `ər ɛr ɪr ʊr` (r-colored)
  - diphthong: `eɪ aɪ ɔɪ aʊ oʊ`
  - `ə` = short, unrounded, unstressed  · `ʌ` = short, unrounded, stressed
  - **weak "happY" vowel `/i/`** = `short, unrounded, unstressed` — the unstressed *ee*-ish end of *lobby, only, he, every*; keep it **distinct from long `/iː/`** (week, fifty).
  - **unstressed r-colored schwa `/ər/` (= `/ɚ/`)** = `r-colored, unstressed` — the weak "er" in *our, over, printer, corner*; keep it **distinct from stressed `/ɜːr/`** (first, bird).
  - **Cover every vowel sound.** Include weak `/i/` and `/ər/` when present — don't fold them into `/iː/` or `/ɜːr/`. **r-colored vowels get their OWN card** — file `/ɑːr/` (far, car, start, are, card) under `/ɑːr/` (`"ar" · long, r-colored`) and `/ɔːr/` (floor, for, corner, door, more) under `/ɔːr/` (`"or" · long, rounded, r-colored`), **not** under their base `/ɑː/` or `/ɔː/`. A word with two nuclei (e.g. *our* `/aʊər/`) appears under both `/aʊ/` and `/ər/`.
  - **Always write the FULL label in the JSON.** The HTML renderer (`build_html.py`) displays only the **marked** attributes (`long`, `rounded`, `stressed`, `r-colored`); it **drops the quoted keyword** and hides the unmarked defaults (`short`, `unrounded`, `unstressed`) and the category tag (`diphthong`) — the IPA symbol + example words already carry those. So `"ee" · long, unrounded` displays as just `long`, `"air" · r-colored` as `r-colored`, `"ur" · long, r-colored` and `"ar" · long, r-colored` as `long, r-colored`, `"or" · long, rounded, r-colored` as `long, rounded, r-colored`, `"uh" · short, unrounded, stressed` as `stressed`, and `"ih" · short, unrounded` displays as **nothing** (symbol-only card).
- `words` — the words from the paragraph, each followed by its `/IPA/` (e.g. `it /ɪt/ · fif·ty /fɪf-/ · him /hɪm/`). Separate entries with ` · `.

### Phase 3.5 — Cross-check inline IPA ↔ nuclei (do this before writing)

The inline `ipa` string and the `nuclei` breakdown describe the **same sounds** and must agree exactly — and both must match the **dictionary form** of each word. Verify this paragraph:

- **Dictionary is authoritative.** Each word's `/IPA/` inline and in `nuclei` must equal its `vocab/US_IPA.json` entry (apart from the two allophonic overrides for `the`/`a`). If a word looks wrong, fix it by editing the dictionary entry and re-merging — not by diverging in the JSON.
- **Same word, same transcription.** A word's `/IPA/` in the `nuclei` `words` list must be byte-identical (symbols, length marks `ː`, stress marks `ˈ`/`ˌ`) to how that word is written inside the inline `ipa`. If they differ, fix one — they cannot disagree.
- **Length mark must match the category.** A word filed under a **long-vowel** nucleus must carry the length mark inline. E.g. the pronoun **"you" → `/juː/`** (file under `/uː/`, write `juː` inline) — never short `ju`, or the `/uː/` scan won't find it. If you genuinely want a weak/short form, you must add the matching short-vowel nucleus instead of filing it under the long one.
- **Stress must not spell a different word.** Place stress on the syllable the intended word actually stresses. E.g. "fifty" = `/ˈfɪfti/` (trochee) — writing `/fɪfˈtiː/` spells **"fifteen"**. The unstressed second syllable of "fifty" is weak `/i/`, not long `/iː/`.
- **Keep secondary stress in both places.** Compounds like **laptop `/ˈlæpˌtɑːp/`**, breakout, stand-ups carry `ˌ` on the second element — write that `ˌ` in the inline `ipa` too, not only in the nuclei `words`.
- **Pick one stress per word and use it everywhere.** If "upstairs" is `/ʌpˈstɛrz/` inline (primary on the 2nd syllable), the nuclei must reflect that — `up` gets secondary `ˌʌp-`, not primary `ˈʌp-`. Don't let the two sections imply different stress.
- **Coverage both directions.** Every vowel symbol that appears in the inline `ipa` must belong to some nucleus card, and every nucleus must point at a vowel actually present inline. No orphans on either side.

### Phase 4 — Write just this section

Do **not** hand-edit the JSON. Hand the driver the `ipa` + `nuclei` you built for this one paragraph; it fills `en` verbatim from the story, upserts the section at `next_index`, preserves every other section, and creates the file (with `title` + standard `subtitle`) on the first run:

```bash
echo '{"ipa":"/ … /","nuclei":[{"ipa":"/ɪ/","label":"\"ih\" · short, unrounded","words":"it /ɪt/ · him /hɪm/"}]}' \
  | python .claude/skills/vocab-ipa-generate/paragraph_tool.py set vocab/stories/{yymmdd}_{slug}.md vocab/json/{slug}_ipa.json {next_index} -
```

(For a large payload, Write it to a temp `.json` file and pass that path instead of `-`.)

### Phase 5 — Render the HTML

```bash
python .claude/skills/vocab-ipa-generate/build_html.py vocab/json/{slug}_ipa.json
```

This writes `vocab/html/{slug}_ipa.html`. Do not edit the HTML by hand — re-run the builder after any JSON change. Sections that still lack `nuclei` render as English + IPA only, so the viewer is usable while paragraphs are still being filled in.

### Phase 6 — Report

State which paragraph you just did and how many remain, e.g. *"Transcribed paragraph 2 of 9. Run the skill again to do paragraph 3."* Give the two output paths and note the HTML opens by double-click (no server needed). If `next_index` was the last one, say the viewer is now complete.

## Rules

1. **One paragraph per run.** Transcribe only the paragraph the driver reports as `next_index`; never loop over the whole article. Done = section has a non-empty `nuclei`.
2. **Source is the plain story only.** Never create or rely on a `*_ipa.md` file. The driver owns segmentation (`paragraph_tool.py next`); don't re-split paragraphs yourself.
3. **`vocab/US_IPA.json` is the ground-truth dictionary.** Use the `found` map verbatim; generate only the `missing` words; merge them back (`ipa_lookup.py merge`, which never overwrites). Assemble the inline `ipa` and `nuclei` from these dictionary forms — to change a word's pronunciation, edit the dictionary, not the per-story JSON.
4. **JSON sections are written by the driver; HTML is generated.** Upsert each section with `paragraph_tool.py set` (preserves other sections, fills `en` verbatim). Produce the HTML via `build_html.py`, never by hand.
5. **One card per paragraph** — never split a paragraph into per-sentence sections. The paragraph gets its own `nuclei` analysis (merged across its sentences, computed from that paragraph's words only).
6. **General American, phonemic `/ /`.** Be consistent with the phoneme set and stress/length marks.
7. **Output naming:** `vocab/json/{source_stem}_ipa.json` and `vocab/html/{source_stem}_ipa.html`.
8. **Inline IPA and nuclei must agree (Phase 3.5).** Same word → identical `/IPA/` in both; length mark matches the nucleus category (pronoun "you" = `/juː/`); stress lands on the right syllable so it doesn't spell another word ("fifty" `/ˈfɪfti/`, not `/fɪfˈtiː/`); secondary stress (`ˌ`) written in both inline and nuclei (laptop `/ˈlæpˌtɑːp/`); one stress per word used consistently; every inline vowel maps to a nucleus and vice versa.
