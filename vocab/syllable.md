# Components of a Syllable

A **syllable** is built from **consonants** and a **vowel**. The way linguists name the parts is below.

## The two big building blocks
- **Vowel** — the core sound (a, e, i, o, u, and sounds like the schwa `ə`)
- **Consonant** — sounds made by blocking/restricting air (b, d, k, s, t, etc.)

## The structural parts of a syllable
A syllable splits into **Onset** + **Rhyme**, and the Rhyme splits into **Nucleus** + **Coda**:

```
            SYLLABLE
           /        \
       Onset        Rhyme (Rime)
                    /      \
               Nucleus     Coda
```

| Part | What it is | Required? |
|------|-----------|-----------|
| **Onset** | consonant(s) **before** the vowel | optional |
| **Nucleus** | the vowel (the loud core) | **required** — every syllable must have one |
| **Coda** | consonant(s) **after** the vowel | optional |
| **Rhyme/Rime** | Nucleus + Coda together (what makes words rhyme) | — |

## Examples
- **"cat"** /kæt/ → onset `k` · nucleus `æ` · coda `t`
- **"floor"** /flɔːr/ → onset `fl` · nucleus `ɔː` · coda `r`
- **"go"** /ɡoʊ/ → onset `ɡ` · nucleus `oʊ` · **no coda**
- **"at"** /æt/ → **no onset** · nucleus `æ` · coda `t`

## Short answer
The pairing is **consonant** and **vowel** (the **nucleus**). Structurally, the full set of component names is **onset, nucleus, coda** (with **rhyme** = nucleus + coda).

One related note from IPA: **`ˈ` (stress)** and **`ː` (length)** describe syllables too, but the actual *components* are the onset / nucleus / coda above.
