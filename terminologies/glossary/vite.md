# Vite

A fast **frontend build tool and dev server**. During development it serves your React code to the browser instantly (no slow rebuild on every save); for production it **bundles** everything into small optimized files. It's the engine that runs and packages the frontend. *Example:* While Alan edits a button's color, Vite updates it in Chloe's-eye-view in the browser the instant he hits save — no waiting. When it's time to ship, Vite squashes all the React files into a few tiny ones the browser can download quickly.
