# PostgreSQL

A free, industrial-strength **relational database**: data lives in tables with rows and columns, related tables joined by keys, and every change protected by transactions (all-or-nothing). It's where the *real, permanent* data sits. *Example:* Every note Chloe has ever written is a row in a `notes` table inside Postgres, and her account is a row in a `users` table linked to those notes by her user id. Close the browser, reboot the server — the rows are still sitting there, safe.
