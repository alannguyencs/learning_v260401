# Client–server model

The bedrock pattern of the web: a **client** (the browser) sends requests, a **server** (your backend) processes them and sends responses. Neither trusts the other's memory — every request stands alone. *Example:* Chloe opens the app in her browser (the client) and it shouts a question across the internet to Alan's server: "give me Chloe's profile." The server does the work and shouts the answer back. They never share a brain — every time Chloe wants something, her browser has to ask again.
